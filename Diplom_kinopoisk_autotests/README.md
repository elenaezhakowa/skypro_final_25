# Кинопоиск Автотесты — Дипломный проект

Цель проекта: Автоматизация UI и API тестирования сайта КиноПоиск (https://www.kinopoisk.ru/) с использованием Python, Pytest, Selenium и Allure. Система разработана с возможностью интеграции с живой средой, обеспечивая полную совместимость с продуктом.

# Суть проекта

Создана комплексная инфраструктура автоматизированного тестирования, охватывающая интерфейс сайта и его API. Благодаря чётко выстроенному процессу тестирования, достигается высокая надёжность продукта и быстрое выявление багов.

# Архитектура и технологии

- Python 3.x: основной язык программирования.
- Pytest: фреймворк для организации и запуска автотестов.
- Selenium: поддержка полного цикла функциональных тестов, связанных с поведением браузера.
- Requests: интеграция с официальным API сайта для API-тестирования.
- Allure: инструмент для удобной генерации отчётности о прохождении тестов.

-  Структура проекта

Diplom_kinopoisk_autotests/
├── tests/
│   ├── test_ui.py     # Функциональные UI-тесты
│   └── test_api.py     # Интеграционные API-тесты
├── conftest.py        # Общие настройки и фикстуры
├── requirements.txt   # Требования и зависимости
└── README.md          # Руководство по эксплуатации проекта

# Процесс запуска тестов

1 Установка зависимостей:

   
   pip install -r requirements.txt
   
2 Запуск тестов:

   
   pytest tests/ --alluredir=allure-results
   
3 Просмотр отчёта:

   
   allure serve allure-results

# Охват тестов

UI-тесты:

- Загрузка главной страницы сайта.
- Поиск фильма («Зеленая миля», «Форрест Гамп»).
- Авторизация зарегистрированного пользователя.
- Покупка билетов в кинотеатре.
- Работа с фильтрацией фильмов.

API-тесты:

- Поиск фильмов по году выпуска.
- Просмотр деталей фильма по ID.
- Проверка отзывов и рейтингов фильмов.
- Фильтрация фильмов по различным критериям (рейтингу, жанру, стране производства).
- Управление сессиями и аутентификацией.

# Особенности проекта

- Интеграция с живой средой: тесты направлены на реальную среду, обеспечивая полное покрытие основных аспектов функционала.
- Масштабируемость: архитектура спроектирована с расчётом на расширение и дополнение новыми видами тестов.
- Удобная документация: чёткая структура документации облегчает понимание и сопровождение проекта.
